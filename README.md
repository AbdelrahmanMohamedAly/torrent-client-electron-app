# CURRENT

A free, local desktop BitTorrent client 

![CURRENT screenshot](docs/screenshot.png)

## Features

- Add `.torrent` files or magnet links
- Transfer list with progress, peers, speeds, ETA, ratio
- Sidebar filters (Downloading, Seeding, Completed, etc.)
- Details: General / Content / Pieces
- Downloads saved to `Downloads/CURRENT`
